# Programación orientada a objetos
## PD2: STANDS

### Requisitos funcionales:
* **(Objetivo)** El sistema deberá notificar a las editoriales que su reserva está pronto de vencer (Fecha limite).
* **(Objetivo)** El sistema deberánotificar a las editoriales que su fecha límite de pronto pago de su reserva está pronto de vencer.
* **(Objetivo)** El programa deberá realizar un descuento del 15% del precio del stand que se tiene reservado si se realiza el pronto pago.
* El programa deberá imprimir los datos genéricos de la editorial que se encuentra presente, además de las reservas que tiene apartado.
* El programa deberá imprimir detalladamente las reservas de la editorial especificando todos los datos de los stands además de su precio con el descuento si se realiza el pronto pago.
* **(Simple)** El programa deberá imprimir una interfaz de registro para poder registrar su editorial en la pagina.
* **(Opcional)** El programa deberá imprimir una interfaz simple del croquis de las editoriales que existen en el espacio de la FILEY.

### Requisitos funcionales extra:
* El sistema permitirá desbloquear los stands para aquellas editoriales que siempre apartan en el momento en donde las editoriales especiales se registren en el programa dando un intervalo de tiempo de un día.

### Requisitos no funcionales:
* **(Opcional interfaz)** La interfaz tendrá un diseño simple e intuitivo para poder mover fácilmente.
